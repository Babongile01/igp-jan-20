name of the job --> ci-job

ci script --> 

pipeline
{
	agent any
	stages
	{
		stage('Checkout')
		{
			steps
			{
				git  'https://github.com/jsachdev07/igpaug23.git'
			}
		}
		
		stage('Compile')
		{
			steps
			{
				sh 'mvn compile'
			}
		}

		stage('Test')
		{
			steps
			{
				sh 'mvn test'
			}
		}

		stage('Packaging')
		{
			steps
			{
				sh 'mvn package'
			}
		}
     }
}

3. Deployment using docker container


steps

1. install docker on the same vm where jenkins is installed 

> apt install docker.io -y 

2. I need to give priviliges to jenkins user to run docker commands

(default ownership on this file is root user and docker group) change it from docker group to jenkins group 
> sudo chown root:jenkins /var/run/docker.sock

3. store the dockerhub credentials in jenkins global credentials that will be referred using some id (mydockerhubcred)

4. we need to install docker pipeline plugin on jenkins so that I can pass credentials using id (mydockerhubcred)

5. write dockerfile and push it to github along with the sourcecode



job-name --> ci-cd-job

jenkins will refer the job using a variable called as JOB_NAME

when you execute the job, you create a build (1, 2, 3, 4,...) BUILD_NUMBER


script --> 


pipeline
{
	agent any
	stages
	{
		stage('Checkout')
		{
			steps
			{
				git 'https://github.com/jsachdev07/igpaug23.git'
			}
		}
		
		stage('Compile')
		{
			steps
			{
				sh 'mvn compile'
			}
		}

		stage('Test')
		{
			steps
			{
				sh 'mvn test'
			}
		}

		stage('Build')
		{
			steps
			{
				sh 'mvn package'
			}
		}
		
		stage('Build Docker Image')
		{
			steps
			{
			    sh 'cp /var/lib/jenkins/workspace/$JOB_NAME/target/ABCtechnologies-1.0.war /var/lib/jenkins/workspace/$JOB_NAME/'
				sh 'docker build -t ABCtechnologies:$BUILD_NUMBER .'
				sh 'docker tag ABCtechnologies:$BUILD_NUMBER jsachdev07/ABCtechnologies:$BUILD_NUMBER'
			}
		}

		stage('Push Docker Image')
		{ 
			steps
			{   
			    withDockerRegistry([ credentialsId: "mydockerhubcred", url: "" ])
			    {
			       sh 'docker push jsachdev07/ABCtechnologies:$BUILD_NUMBER'
			    }
			}
		}

		stage('Deploy as container')
		{
			steps
			{
				sh 'docker run -itd -P jsachdev07/ABCtechnologies:$BUILD_NUMBER'
			}
		}   
	}
		
}



dockerfile --> 

FROM iamdevopstrainer/tomcat:base
COPY ABCtechnologies-1.0.war /usr/local/tomcat/webapps/
CMD ["catalina.sh", "run"]

package location --> /var/lib/jenkins/workspace/$JOB_NAME/target/ABCtechnologies-1.0.war
dockerfile --> /var/lib/jenkins/workspace/$JOB_NAME/dockerfile 


to run docker image build my package(war) and dockerfile should be in same location

4. deployment to kubernetes


steps:

1. deploy a k8s cluster (GKE / EKS) with 2 worker nodes
2. instal kubectl on jenkins server 
> apt install kubectl -y 
3. you need to copy the kubeconfig file of your k8s cluster to jenkins vm on path /var/lib/jenkins/
4. chown jenkins:jenkins /var/lib/jenkins/kubeconfig
5. write the pod.yaml file and svc.yaml file like below and upload it on github along with your sourcecode

metadata:
spec:
